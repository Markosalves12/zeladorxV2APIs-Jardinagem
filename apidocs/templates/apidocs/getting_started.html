Primeiros passos

Todas as rotas usam autenticação por token. Faça login uma vez e reutilize o token nas próximas chamadas.

1. Login

O login usa os campos username e password. O username é o e-mail do usuário.

POST/api/login
import requests

body = {
    "username": "seu.email@empresa.com.br",
    "password": "SUA_SENHA",
}

response = requests.post("{BASE_URL}/api/login", body)
response.json()

# {
#     'token': 'SEU_TOKEN',          # token de acesso
#     'id_random': '6uW6BnjPFHyd',   # id randômico único
#     'user_id': 1,                  # chave primária
#     'username': 'zeladorx',
#     'email': 'zeladorx@zeladorx.com.br',
#     'is_superuser': True,          # superusuário do ecossistema contratado
# }

2. Envie o token

Todas as rotas precisam do token no cabeçalho Authorization.

headers = {
    "Authorization": f"Token {response.json()['token']}"
}

response = requests.get("{BASE_URL}/api/areas/ListAreasJardinagem/", headers=headers)

3. Regras gerais

  • Cada rota exige um código de permissão do usuário (veja Códigos de permissão em cada plataforma).
  • Os registros são identificados pelo id_random, nunca pelo id numérico.
  • As listas são paginadas com 15 itens por página (?page=2).
  • Antes de excluir, consulte a rota IfDelete... para saber se o registro pode ser removido.
